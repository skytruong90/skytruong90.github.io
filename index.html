I am a software engineer building mission-critical software for the defense and aerospace industry. My work spans C++ and Python development, object-oriented design, unit and integration testing, and Linux-based DevSecOps workflows across GitLab CI/CD, Jenkins, Kubernetes, and Docker.

I have delivered software across ICBM flight-dynamics modeling for LGM-35A Sentinel, ground-framework data processing for FORGE OPIR, and 6DOF missile simulation for LRPM. In each case the job was the same: turn technical requirements into design, code, tests, and validated results that engineers and program offices can actually stake decisions on.

I care most about the part of the work that is easy to skip — traceability, reproducible builds, and knowing exactly why a model behaves the way it does.
